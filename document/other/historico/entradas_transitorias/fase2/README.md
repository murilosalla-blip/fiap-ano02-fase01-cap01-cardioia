# Compatibilidade da Fase 2

Mantenho nesta pasta somente as entradas de compatibilidade. Concentro o código em [src/fase2](../src/fase2/), as dependências em [config/fase2](../config/fase2/) e a documentação em [document/fase2](../document/fase2/README.md).

Preservo `streamlit run fase2/app.py` e `python -m pip install -r fase2/requirements.txt` para a publicação e para a execução já utilizada. Consulto os caminhos atuais dos demais comandos no [guia da Fase 2](../document/fase2/README.md).
